# Social Media Analytics — Profile & Certificate Authentication Hub

**ALARD School of Engineering & Technology, ALARD University, Pune (A.Y. 2026–27)**  
**Guided by:** Prof. Krati Shrivastava

## Features
- **LinkedIn Profile Lookup (`profile-linkedin-profile.txt`)**: Search any candidate by name and click **Get Information** to load their extracted LinkedIn profile, education, skills, NLP sentiment score, and credential audit report.
- **Cryptographic Certificate Verifier**: Upload any PDF/image certificate or run a verification check with SHA-256 hash validation, displaying both **Authenticated (`Yes, that is authenticated`)** and **Unauthenticated (`No, this certificate is NOT authenticated`)** results.
- **Dark Mode & Light Mode**: Built-in theme toggle in the top header bar.

## Getting Started

```bash
npm install
npm run dev
```
